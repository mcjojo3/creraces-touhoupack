# CreRaces Touhou Pack

Experimental Touhou Project races for CreRaces, built as a racepack. It starts with Flandre Scarlet.

The races are meant to be overpowered, to stay true to their source. They need Twilight Lib for their cosmetics.

Racepacks work like datapacks: zip the contents of this folder (not the folder itself) and put the zip in the mods folder next to the CreRaces jar. The same pack works with both the 1.20.1 and 1.21.1 versions of CreRaces.

## Flandre Scarlet

- **Passives:** sunlight burns her and rain or water weakens her; she drinks blood from her hits, flies on crystal wings, breaks through armour and builds madness into a frenzy.
- **Starting abilities:** Kyuu-tto Shite Dokan, Taboo "Lævateinn", Taboo "Kagome, Kagome", Bat Form.
- **Researchable:** Taboo "Cranberry Trap", Forbidden Barrage "Starbow Break", Secret Barrage "And Then Will There Be None?", QED "495 Years' Wave", Vampire Bite, Taboo "Four of a Kind".
